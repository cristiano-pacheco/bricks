# Run an explicit decorator chain

Follow the numbered setup in the [consumer guide](../../references/ucdecorator/manual.md). Copy this directory's `main.go` into `cmd/quote/main.go` in an application module that depends on Bricks. The factory and observability examples also include configuration to copy into `cmd/quote/config/base.yaml`.

Run with quantity `2` for success or `0` for a returned application error. The guide gives the full command, expected output, and cleanup ownership. These examples have not been compiled or executed in this documentation task because the user waived execution checks.
